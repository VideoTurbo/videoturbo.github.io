title: 云 GPU
description: 按需租用云 GPU，或通过 SSH 接入任意 Linux 显卡主机。
---

在控制台“云主机”页按需租用云 GPU，主程序自动在云主机上装好服务。

## 怎么连接

主程序用 SSH 登录云主机安装服务，并保持一条 SSH 反向隧道：云主机上的服务连本机的 `127.0.0.1:8766`，流量经隧道回到主程序。
所以只需要主程序能 SSH 登录云主机，**不需要公网 IP 或端口转发**。

主程序第一次连接时会记录云主机的 SSH 主机密钥。之后密钥不一致会拒绝连接；如果云主机重装过系统，在创建任务上选择“信任新身份并重新安装”。

## 计费与关机

:::caution
租到就开始计费。
:::

通过平台插件租用的云主机，绑定后可以设为跑完自动关机。

## 手动 SSH

内置的“手动 SSH”可以接入任何提供 SSH 登录的 Linux 显卡主机，不依赖平台接口：在平台网页上开机，
在主程序里填写地址、端口、账号和密码，主程序通过 SSH 安装服务并建立隧道。

- 登录账号不必是 root；缺少系统依赖时用 root 或免密 sudo 安装。
- 没有平台接口，所以**不能开机、关机、销毁或保存镜像**，也没有自动关机，需要自己去平台操作。
- 云平台重启实例后登录地址或端口变化时，需要重新添加。

## 更多平台

其他云平台通过[插件](../plugins/)接入。
