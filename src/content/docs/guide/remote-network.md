---
title: 显卡电脑不在同一局域网
description: 显卡电脑和主程序不在同一个网络时如何接入。
---

这一页只针对[自己安装的显卡电脑](../install-worker/)。这类电脑会主动连主程序，所以必须能访问到主程序。

[云 GPU](../../features/cloud-gpu/) 由主程序用 SSH 登录后自动安装，并通过 SSH 反向隧道连回主程序，不需要公网 IP 或端口转发，不用看这一页。

## 推荐：Tailscale

主程序所在机器和显卡电脑都加入同一个 [Tailscale](https://tailscale.com/)（或 WireGuard）网络，
安装显卡电脑服务时，主程序地址填主程序的 Tailscale 地址。

## 必须走公网时

:::danger
不要把 8765 端口直接映射到公网。
:::

只把机器接入端口 **8766** 映射到公网，并放在 HTTPS 反向代理之后。安装显卡电脑服务时，主程序地址填这个 HTTPS 地址。

## Linux 机器也可以用 SSH 接入

如果主程序能 SSH 登录那台 Linux 显卡电脑，也可以在控制台“云主机”页用“手动 SSH”把它当云主机接入，
由主程序自动安装服务、建立隧道，不需要开放 8766。限制见[云 GPU · 手动 SSH](../../features/cloud-gpu/#手动-ssh)。
