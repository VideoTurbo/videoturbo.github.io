---
title: 生成字幕
description: 扫描影片并提交字幕任务。
---

1. 点顶部的“**扫描影片**”。扫描不会自动开始任务。
2. 在“字幕生成 → 待处理”里勾选影片，点“**生成字幕**”。建议先选一部试试。
3. 字幕写在影片旁边，例如 `电影名.zh.default.srt`。配置了媒体服务器时会自动刷新。

已有目标语言字幕的影片直接记为已完成；自带原文字幕的影片只翻译、不识别。

## 支持的语言

| 语言 | 原文 | 译文 | 字幕文件名 |
| --- | --- | --- | --- |
| 日语 | ✓ | ✓ | `片名.ja.default.srt` |
| 英语 | ✓ | ✓ | `片名.en.default.srt` |
| 韩语 | ✓ | ✓ | `片名.ko.default.srt` |
| 简体中文 | | ✓ | `片名.zh.default.srt` |
| 繁体中文 | | ✓ | `片名.zh-TW.default.srt` |

每个媒体库单独选影片语言和字幕语言，在“系统设置 → 媒体库”里修改。
